\subsection{Task Workflow}
\begin{enumerate}
  \item Create an issue with acceptance criteria and evidence links; assign an owner, deadline, effort, and dependencies.
  \item Move the task to \texttt{Ready}, create a separate branch from \texttt{main}, and implement the change.
  \item Commit using Conventional Commits (for example, \texttt{feat:}, \texttt{fix:}, \texttt{docs:}, or \texttt{test:}).
  \item Open a PR linked to the issue and obtain at least one peer approval before merge. For documentation, review the content, compile LaTeX, and inspect the PDF; for application code, run configured lint, unit tests, and any agreed coverage checks.
  \item Merge only after the required peer approval and applicable checks pass, then mark the issue \texttt{Done} and attach the completed work or other evidence.
\end{enumerate}

Never commit \texttt{.env} files, passwords, API keys, or service-account credentials.
